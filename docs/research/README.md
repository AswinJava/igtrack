# Research Log

Findings about Instagram source behavior, one file per question. Each document
MUST include: date, question, source, finding, confidence, and implementation
consequence. Prefer official docs and reproducible fixtures over stale
reverse-engineering posts.

Template:

```markdown
# <short question>

- Date: YYYY-MM-DD
- Question: <what we needed to know>
- Source: <official doc / observed behavior / fixture / OSS impl>
- Finding: <what we learned>
- Confidence: HIGH | MEDIUM | LOW
- Implementation consequence: <what changes in IGTrack because of this>
```
