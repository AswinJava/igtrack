Three states, never blurred

Most analytics tools show a number and stop there. IGTrack keeps the distinction that matters: what was seen, what was computed from what was seen, and what the platform refuses to expose.

Observed

Raw platform reads

Profile snapshots, stories, posts, comments, tagged media and follow counts — stored with source id, capture time, confidence and content hash.

Derived

Computed, traceable

Follow deltas, caption edits, story lifetimes, relationship rankings. Every derived row points at the observations it came from.

Refused

Absence, with a reason

Follower rosters, liker lists, highlight contents and media bytes are named as unavailable. A truncated scan is stored, labelled and never diffed.

One command, one dossier

Resolve a handle, run every stage the configured sources support, rank relationships and return a single cited dossier — including the gaps.

igtrack — investigate 
$ igtrack investigate @aurora.wilde

  Account      aurora.wilde · ig:17841400000000001 · public

  Evidence     41 observations · every row has a source id and SHA-256 hash

Built like an instrument

A Postgres-backed queue, a resumable scanner and an append-only ledger — the parts that make a diff trustworthy.

∑

Append-only evidence ledger

Observations are never rewritten. Corrections are new rows, so history stays auditable months later.

⇄

Deltas with provenance

Every change row links to the two observations it compares. Nothing is inferred from a missing page.

◐

Partial scans never diff

Completeness is recorded per scan. A truncated read can inform, but it can never produce a false claim.

⟳

Resumable workers

Leases, heartbeats and checkpoints on a Postgres queue — a restart resumes the scan instead of losing it.

▦

Period reports

Weekly, monthly and quarterly reports where every section is OBSERVED, DERIVED, EMPTY or UNAVAILABLE.

⌘

38-tool MCP server

The CLI and the MCP server call the same operations layer. Your agent gets identical results, not a second API.

Running in two minutes

Node 22+, pnpm and PostgreSQL 16. The default dataset is synthetic, deterministic and offline — safe to run forever.

Clone and install

Dependencies and workspace links.

git clone https://github.com/AswinJava/igtrack.git
cd igtrack && pnpm install

Start PostgreSQL

Compose brings up Postgres 16 on 5432.

cp .env.example .env
docker compose up -d

Set up and investigate

Migrations, synthetic demo, first dossier.

pnpm igtrack setup
pnpm igtrack investigate aurora.wilde

Speak agent, natively

One operations layer, two surfaces. The CLI is JSON-first; the MCP server exposes the same operations over stdio with no drift between them.

  • 38 MCP tools for observation, derivation, reporting and research.
  • 25 declared capabilities, each with its state, supplier and reason when the answer is no.
  • Claims ledger with a closed predicate registry, source URL, excerpt and hash.
  • No telemetry. Self-hosted, your database, your history.
